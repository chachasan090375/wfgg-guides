# WfGg Guides

Dépôt public des guides WfGg pour Last War.

## Structure

- `/` : accueil des guides
- `/season6/` : Guide Saison 6
- `/interseason/` : Guide Inter-Saison

Projet prévu pour Cloudflare Pages avec déploiement automatique depuis la branche `main`.

Le simulateur WfGg sera ensuite isolé dans son propre projet `wfgg-simulator`.
