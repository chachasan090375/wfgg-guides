Rampage Boss

Temporary boss event — official current name confirmed in July 2026

← Home

What is it?

A temporary event centered on upgradable Zombie Bosses. Official July 2026 version notes confirm the current English name “Rampage Boss”.

When?

Availability depends on event rotations. Treat it as temporary content, not a permanent daily event.

Preparation

Check milestone requirements before spending stamina or resources and upgrade only toward reachable tiers.

How it works

The July 2026 update adjusted the maximum upgradeable level of each event boss to level 15.

What to do

Target realistic reward milestones and coordinate if collective goals are present.

Avoid

Do not use the older community label “Bosses Gone Wild” as the current official name.

Rewards

Rewards depend on the active rotation; always check the in-game preview.
